# 공개와 데이터 경계

공개 저장소: https://github.com/poshygg/evidence-harness

공개 범위는 범용 도구·설계·스키마·작업 템플릿·합성 예제·자동 검사입니다. 실제 과제 내용, 제공 데이터, 개인 접속 정보, 실제 구현 결과와 실행 원장은 포함하지 않습니다. 실행 기록은 공개 소스 디렉터리 밖의 작업공간 .evidence-harness에 둡니다.

이 프로그램은 자동 push·업로드·원격 AI 호출·텔레메트리를 구현하지 않습니다. 등록된 검사 코드는 신뢰해야 하며, 코드 자체의 외부 통신을 이 하네스만으로 차단하지는 못합니다. 실제 환경의 네트워크·파일·도구 제한을 따릅니다.

사용한 공개 자료의 커밋과 라이선스를 기록합니다. 개별 행사에서 요구하는 공개 상태 유지 기간, 허용되는 설치 방식·도구·제출 형식은 해당 규정으로 확인합니다. 공개 소스를 가져오는 행위와 실제 작업물을 외부로 보내는 행위를 구분합니다.

현재 구현은 v0.1.0입니다. 초기 설계의 부가 기능 중 events.jsonl 자동 내보내기, 별도 메모리 샘플러, OS 전체 메모리 상한, 대시보드는 구현하지 않았습니다. 실행의 실제 기록 구조는 core.py와 runner.py 및 현재 도구 계약을 따릅니다.
